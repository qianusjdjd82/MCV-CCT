Chapter Overview

This chapter builds on Chapter 8 (equations for lines and planes in 3-space). We analyse geometric relationships: intersection, parallel, and coincident cases for lines and planes. We also solve linear systems and calculate perpendicular shortest distances between points, lines, and planes.

Learning Goals

  • Identify all possible intersection cases for lines and planes in \(\mathbb{R}^3\)
  • Solve systems of linear equations and link algebraic results to 3D geometry
  • Apply distance formulas for point-to-line and point-to-plane
Big Idea of Chapter 9: Connect 3-D space geometry with linear algebra. The number of solutions (0, one, infinitely many) of a linear system tells us how these lines and planes intersect. Finally we compute perpendicular shortest distances.
3D Coordinate Space (\(\mathbb{R}^3\)) Concept Map
Geometry Meets Algebra: Points, lines, and planes are positioned in \(\mathbb{R}^3\). Normal vectors (\(\vec{n}\)) and direction vectors (\(\vec{d}\)) govern intersections and shortest perpendicular distances (\(d\)).

9.1 The Intersection of a Line with a Plane and the Intersection of Two Lines

Definition

  • Skew lines: Two lines in \(\mathbb{R}^3\) that are not parallel and do not intersect. Skew lines only exist in 3-dimensional space.
  • Intersecting lines: Two lines share exactly one common point.
  • Coincident lines: Two lines lie exactly on top of each other; infinitely many shared points.
  • Parallel lines: Direction vectors are scalar multiples of each other (\(\vec{d}_1 = k\vec{d}_2\)).

Core Concepts

Possible cases for two lines in \(\mathbb{R}^3\):
1. Intersect at exactly one point;  2. Coincident;  3. Parallel distinct;  4. Skew (only for \(\mathbb{R}^3\)).

Possible cases for a line and a plane:

  1. Intersect at one single point
  2. Line is parallel to the plane with no intersection
  3. The entire line lies inside the plane (infinitely many intersection points)

Solving strategy: Substitute the parametric equations of the line into the Cartesian plane equation, solve for parameter \(t\), and judge cases from the number of valid \(t\)-solutions.

Important Formulas

Vector equation for line: \(\vec{r} = \vec{r}_0 + t\vec{d},\ t \in \mathbb{R}\)

Parametric line: \(x = x_0 + td_x,\ y = y_0 + td_y,\ z = z_0 + td_z\)

Cartesian plane: \(Ax + By + Cz + D = 0\)

Quick Example

Given a line’s parametric equations, substitute \(x, y, z\) into the plane’s Cartesian equation. If you get one value for \(t\) \(\rightarrow\) one intersection point. If \(t\) cancels and you get a true statement (\(0=0\)), the line lies on the plane; if you get a false statement (\(0=k,\ k \neq 0\)), the line is parallel and distinct.

Line–Plane & Skew Lines in \(\mathbb{R}^3\)
Visual Check: Skew lines \(L_1\) and \(L_2\) travel in non-parallel directions at different depths in \(\mathbb{R}^3\), so they never meet.

9.2 Systems of Linear Equations

Definition

A system of linear equations consists of two or more linear equations involving the same variables. In three-dimensional space (\(\mathbb{R}^3\)), a linear system typically consists of three equations with three variables (\(x, y, z\)), each representing a plane.

Core Concepts

Possible solution sets for a 3-variable linear system:

  1. Unique solution: The planes intersect at a single point \((x, y, z)\).
  2. Infinitely many solutions: The planes intersect along a common line or are coincident.
  3. No solution (Inconsistent): The system has contradictions (e.g., parallel planes or a triangular prism configuration with no common intersection).

Solving Strategy: Use Gaussian elimination (elementary row operations) on the augmented matrix \([A | B]\) to transform the system into row-echelon form.

Important Formulas

Augmented Matrix Form: \([A | B]\) where \(A\) is the coefficient matrix and \(B\) is the constant column vector.

Elementary Row Operations:
1. Interchange two rows (\(R_i \leftrightarrow R_j\)).
2. Multiply a row by a non-zero scalar (\(kR_i \to R_i,\ k \neq 0\)).
3. Add a multiple of one row to another (\(R_i + kR_j \to R_i\)).

Quick Example

For a system like \(x+y+z=6\), \(2x-y+3z=14\), and \(x+2y-z=2\), applying row operations leads to upper triangular form, allowing back-substitution to find the unique solution \((1, 2, 3)\).

Gaussian Elimination & Row-Echelon Outcomes
Reading the Matrix: The bottom row after Gaussian elimination immediately reveals whether the geometry meets at a point, a line/plane (\(0=0\)), or nowhere (\(0=k\)).

9.3 The Intersection of Two Planes

Definition

Two planes in \(\mathbb{R}^3\) can either be parallel distinct, coincident, or intersecting along a straight line.

Core Concepts

Cases:

  1. Parallel distinct: Normal vectors are scalar multiples (\(\vec{n}_1 = k\vec{n}_2\)), but constant terms do not match ratio (\(D_1 \neq kD_2\)); no intersection.
  2. Coincident: Normal vectors and constants are proportional (\(A_1x+B_1y+C_1z+D_1 = k(A_2x+B_2y+C_2z+D_2)\)); infinite solutions (the whole plane).
  3. Intersecting: Normal vectors are not scalar multiples; they intersect along a line. The direction vector of the line is given by \(\vec{d} = \vec{n}_1 \times \vec{n}_2\).

Important Formulas

Line of intersection direction vector: \(\vec{d} = \vec{n}_1 \times \vec{n}_2\)

Quick Example

Cross the normal vectors of two non-parallel planes to get the direction vector of their intersection line, then find a particular point by setting one variable (e.g., \(z=0\)) and solving the remaining 2-variable system.

Two Planes & Cross Product Direction \(\vec{d} = \vec{n}_1 \times \vec{n}_2\)
Why Cross Product Works: The intersection line lies inside both planes simultaneously, so its direction \(\vec{d}\) must be perpendicular to both \(\vec{n}_1\) and \(\vec{n}_2\).

9.4 The Intersection of Three Planes

Definition

The intersection of three planes in \(\mathbb{R}^3\) corresponds to the solution set of a system of three linear equations in three variables (\(x, y, z\)). Geometrically, there are 8 distinct configurations classified into consistent (at least one solution) and inconsistent (no common solution) systems.

Core Concepts

Consistent Systems (Solutions Exist — 4 Cases):

  1. Intersect at a single point: Unique solution \((x, y, z)\); normal vectors are non-coplanar (\(\vec{n}_1 \cdot (\vec{n}_2 \times \vec{n}_3) \neq 0\)).
  2. Intersect along a common line (Sheaf of planes): Infinitely many solutions with 1 parameter (\(t\)); row reduction yields one row of zeros (\(0 = 0\)).
  3. Two coincident planes intersecting a third plane: Intersect along a straight line (1 parameter \(t\)); two equations are scalar multiples of each other.
  4. Three coincident planes: All three equations are scalar multiples; infinitely many solutions with 2 parameters (\(s, t\)).

Inconsistent Systems (No Common Solution — 4 Cases):

  1. Three parallel distinct planes: All normal vectors are scalar multiples, but constants are not proportional.
  2. Two coincident planes parallel to a third: Two equations are multiples, while the third shares the same normal direction with a different constant ratio.
  3. Two parallel distinct planes intersected by a third: Two normal vectors are multiples (with inconsistent constants), while the third cuts across both in two parallel lines.
  4. Triangular prism configuration: Pairs of planes intersect in three parallel lines, but there is no single point common to all three; normals are coplanar (\(\vec{n}_1 \cdot (\vec{n}_2 \times \vec{n}_3) = 0\)), and elimination yields a contradiction such as \(0 = k\) (\(k \neq 0\)).

Important Formulas

Scalar Triple Product Test for Normals: \(\vec{n}_1 \cdot (\vec{n}_2 \times \vec{n}_3)\)

\(\bullet\) If \(\vec{n}_1 \cdot (\vec{n}_2 \times \vec{n}_3) \neq 0 \implies\) Normals are non-coplanar \(\implies\) Unique single-point intersection.

\(\bullet\) If \(\vec{n}_1 \cdot (\vec{n}_2 \times \vec{n}_3) = 0 \implies\) Normals are coplanar \(\implies\) Either a line/plane of intersection or an inconsistent system.

Quick Example

Consider \(\pi_1: x + y + z = 2\), \(\pi_2: 2x - y + z = 4\), and \(\pi_3: 3x + 2z = 8\). Notice \(\vec{n}_1 + \vec{n}_2 = (3, 0, 2) = \vec{n}_3\), so the normals are coplanar. Adding equations (1) and (2) gives \(3x + 2z = 6\), which contradicts \(\pi_3\) (\(3x + 2z = 8\)). Thus, the three planes form a triangular prism with no solution.

Key 3-Plane Geometric Configurations
Decision Workflow: First check if any normal vectors are scalar multiples (parallel/coincident planes). If not, compute \(\vec{n}_1 \cdot (\vec{n}_2 \times \vec{n}_3)\) to distinguish a single point from a sheaf or triangular prism.

9.5 The Distance from a Point to a Line in \(\mathbb{R}^2\) and \(\mathbb{R}^3\)

Definition

The distance from a point \(P\) to a line \(L\) is defined as the length of the perpendicular line segment drawn from point \(P\) to line \(L\). This represents the shortest possible distance between the point and any point on the line.

Core Concepts

  • In \(\mathbb{R}^2\): We can find the shortest distance by projecting vector \(\vec{QP}\) (where \(Q\) is any known point on the line) onto the line's normal vector \(\vec{n} = (A, B)\), leading directly to the standard Cartesian distance formula.
  • In \(\mathbb{R}^3\): Because a line in 3-space does not have a unique normal vector, we construct a parallelogram using a point \(Q\) on the line and the line's direction vector \(\vec{d}\). The area of the parallelogram is \(\|\vec{QP} \times \vec{d}\|\), and dividing by the base length \(\|\vec{d}\|\) yields the perpendicular height \(d\).
  • Distance between parallel lines: Pick any convenient point \(P\) on the first line and compute its perpendicular distance to the second line.

Important Formulas

Point \(P(x_0, y_0)\) to Line \(Ax + By + C = 0\) in \(\mathbb{R}^2\): $$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$

Point \(P\) to Line \(\vec{r} = \vec{r}_0 + t\vec{d}\) (passing through \(Q\)) in \(\mathbb{R}^3\): $$d = \frac{\|\vec{QP} \times \vec{d}\|}{\|\vec{d}\|}$$

Alternative Projection Method in \(\mathbb{R}^3\): $$d = \sqrt{\|\vec{QP}\|^2 - \left(\frac{\vec{QP} \cdot \vec{d}}{\|\vec{d}\|}\right)^2}$$

Quick Example

Find the distance from \(P(3, 1, -2)\) to the line \(\vec{r} = (1, 0, 2) + t(2, -1, 2)\). Let \(Q(1, 0, 2)\), so \(\vec{QP} = (2, 1, -4)\) and \(\vec{d} = (2, -1, 2)\). Then \(\vec{QP} \times \vec{d} = (-2, -12, -4)\), with magnitude \(\sqrt{4 + 144 + 16} = \sqrt{164}\). Since \(\|\vec{d}\| = \sqrt{4 + 1 + 4} = 3\), the distance is \(d = \frac{\sqrt{164}}{3} = \frac{2\sqrt{41}}{3}\).

Parallelogram Area Geometry in \(\mathbb{R}^3\)
Why Cross Product Gives Distance: \(\text{Area} = \text{Base} \times \text{Height} \implies \|\vec{QP} \times \vec{d}\| = \|\vec{d}\| \cdot d\), so dividing by \(\|\vec{d}\|\) isolates the perpendicular distance \(d\).

9.6 The Distance from a Point to a Plane

Definition

The distance from a point \(P\) to a plane \(\pi\) in \(\mathbb{R}^3\) is the length of the perpendicular segment connecting \(P\) to the plane, which equals the magnitude of the scalar projection of vector \(\vec{QP}\) (for any point \(Q\) on \(\pi\)) onto the plane's normal vector \(\vec{n}\).

Core Concepts

  • Projection Geometry: Given any point \(Q(x_1, y_1, z_1)\) on the plane \(Ax + By + Cz + D = 0\), we know \(Ax_1 + By_1 + Cz_1 = -D\). Projecting \(\vec{QP} = (x_0 - x_1, y_0 - y_1, z_0 - z_1)\) onto \(\vec{n} = (A, B, C)\) simplifies cleanly to the Cartesian distance formula.
  • Distance between two parallel planes: Ensure both plane equations have identical normal coefficients \((A, B, C)\), then either pick a point on one plane and find its distance to the other, or apply \(d = \frac{|D_2 - D_1|}{\sqrt{A^2 + B^2 + C^2}}\).
  • Distance between skew lines: Two skew lines lie in unique parallel planes whose common normal is \(\vec{n} = \vec{d}_1 \times \vec{d}_2\). Projecting the vector connecting a point on each line onto \(\vec{n}\) gives the shortest distance between the skew lines.

Important Formulas

Point \(P(x_0, y_0, z_0)\) to Plane \(Ax + By + Cz + D = 0\): $$d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$$

Vector Projection Form (with \(Q\) on the plane): $$d = \frac{|\vec{QP} \cdot \vec{n}|}{\|\vec{n}\|}$$

Distance Between Parallel Planes \(Ax + By + Cz + D_1 = 0\) and \(Ax + By + Cz + D_2 = 0\): $$d = \frac{|D_2 - D_1|}{\sqrt{A^2 + B^2 + C^2}}$$

Distance Between Skew Lines \(L_1\) and \(L_2\): $$d = \frac{|\vec{P_1P_2} \cdot (\vec{d}_1 \times \vec{d}_2)|}{\|\vec{d}_1 \times \vec{d}_2\|}$$

Quick Example

Find the distance from \(P(2, -1, 4)\) to the plane \(2x - y + 2z - 9 = 0\). Substitute the coordinates of \(P\) into the formula: $$d = \frac{|2(2) - (-1) + 2(4) - 9|}{\sqrt{2^2 + (-1)^2 + 2^2}} = \frac{|4 + 1 + 8 - 9|}{\sqrt{9}} = \frac{4}{3}.$$

Scalar Projection of \(\vec{QP}\) onto Normal \(\vec{n}\)
Projection Insight: Regardless of where \(Q\) sits on plane \(\pi\), projecting \(\vec{QP}\) onto the perpendicular normal \(\vec{n}\) always yields the exact vertical height \(d\).

9.1 Practice Questions

Q1: Determine whether the lines \(\vec{r} = (1, 2, 3) + t(1, -1, 2)\) and \(\vec{r} = (2, 1, 5) + s(2, -2, 4)\) are parallel, intersecting, coincident, or skew.

Solution: Direction vectors are \(\vec{d}_1 = (1, -1, 2)\) and \(\vec{d}_2 = (2, -2, 4) = 2\vec{d}_1\), so they are parallel. Testing point \((2, 1, 5)\) in the first line yields a valid consistent parameter \(t=1\). Thus, the lines are coincident.

Q2: Find the intersection point of the line \(x = 1+t, y = 2-t, z = 3+2t\) and the plane \(2x + y - z + 4 = 0\).

Solution: Substitute parametric equations into the plane: \(2(1+t) + (2-t) - (3+2t) + 4 = 0 \implies 5 - t = 0 \implies t = 5\). Substituting \(t=5\) gives the point \((6, -3, 13)\).

Q3: Explain why skew lines can only exist in three-dimensional space (\(\mathbb{R}^3\) or higher) and not in two-dimensional space (\(\mathbb{R}^2\)).

Solution: In \(\mathbb{R}^2\), all lines share the same flat plane, meaning non-parallel lines must cross and parallel lines share the same plane. In \(\mathbb{R}^3\), lines can exist at different elevations without intersecting and without being parallel (skew lines).

Q4: Determine if the line \(\vec{r} = (0, 1, 2) + t(1, 1, 1)\) intersects the plane \(x - y + z = 5\).

Solution: Substitute \(x = t, y = 1+t, z = 2+t\) into the plane equation: \(t - (1+t) + (2+t) = 5 \implies 1 + t = 5 \implies t = 4\). The intersection point is \((4, 5, 6)\).

Q5: Given a line with direction vector \(\vec{d} = (2, 3, -1)\) and a plane with normal vector \(\vec{n} = (4, -1, 5)\), what is their geometric relationship?

Solution: Compute dot product \(\vec{d} \cdot \vec{n} = 2(4) + 3(-1) + (-1)(5) = 8 - 3 - 5 = 0\). Since \(\vec{d} \perp \vec{n}\), the line is parallel to the plane (or lies within it).

9.2 Practice Questions

Q1: State the three possible types of solution sets for a linear system of three equations in three variables.

Solution: 1. Unique solution (single point); 2. Infinitely many solutions (line or plane); 3. No solution (inconsistent system).

Q2: Solve the linear system: \(x + y + z = 6\), \(2x - y + 3z = 14\), \(x + 2y - z = 2\).

Solution: Using Gaussian elimination, the unique solution is \(x = 1, y = 2, z = 3\).

Q3: What does a resulting statement like \(0 = 5\) signify during the row reduction of a linear system?

Solution: It means the system is inconsistent and has no solution.

Q4: Solve the dependent system: \(x + y = 3\) and \(2x + 2y = 6\).

Solution: The second equation is a multiple of the first. There are infinitely many solutions: \(x = t, y = 3 - t\) (\(t \in \mathbb{R}\)).

Q5: What are the three elementary row operations used in Gaussian elimination?

Solution: 1. Interchange two rows; 2. Multiply a row by a non-zero scalar; 3. Add a multiple of one row to another row.

9.3 Practice Questions

Q1: What are the possible geometric relationships between two distinct planes in \(\mathbb{R}^3\)?

Solution: They can either be parallel distinct (no intersection) or intersecting along a straight line.

Q2: Determine the intersection of the planes \(x + y + z = 3\) and \(2x + 2y + 2z = 8\).

Solution: The second plane simplifies to \(x + y + z = 4\). Since constants differ while normal vectors match, they are parallel distinct (no solution).

Q3: How do you find the direction vector of the line of intersection of two intersecting planes?

Solution: By taking the cross product of their normal vectors: \(\vec{d} = \vec{n}_1 \times \vec{n}_2\).

Q4: Find the direction vector for the line of intersection between \(x + y - z = 1\) and \(2x - y + z = 2\).

Solution: \(\vec{d} = (1, 1, -1) \times (2, -1, 1) = (0, -3, -3)\), which is proportional to \((0, 1, 1)\).

Q5: If two planes have normal vectors that are scalar multiples (\(\vec{n}_1 = k\vec{n}_2\)), what can be said about their intersection?

Solution: They are either parallel distinct (no solution) or coincident (infinitely many solutions).

9.4 Practice Questions

Q1: How many geometric configurations exist for the intersection of three planes in \(\mathbb{R}^3\), and how are they divided?

Solution: There are 8 configurations in total: 4 consistent cases (1 single point, 2 line of intersection with distinct planes, 3 line of intersection with two coincident planes, 4 three coincident planes) and 4 inconsistent cases (no common solution).

Q2: Use the scalar triple product of normal vectors to determine whether the planes \(x + 2y - z = 3\), \(2x - y + z = 1\), and \(x + y + z = 4\) intersect at a single point.

Solution: \(\vec{n}_1 = (1, 2, -1)\), \(\vec{n}_2 = (2, -1, 1)\), \(\vec{n}_3 = (1, 1, 1)\). First compute \(\vec{n}_2 \times \vec{n}_3 = ((-1)(1) - (1)(1),\ -(2(1) - 1(1)),\ 2(1) - (-1)(1)) = (-2, -1, 3)\). Then \(\vec{n}_1 \cdot (\vec{n}_2 \times \vec{n}_3) = 1(-2) + 2(-1) + (-1)(3) = -7 \neq 0\). Since the triple product is non-zero, the planes intersect at one unique point.

Q3: Describe the geometry of the system: \(x - y + 2z = 5\), \(2x - 2y + 4z = 10\), and \(3x + y - z = 2\).

Solution: The second equation is exactly \(2\) times the first equation, so those two planes are coincident. The third plane is not parallel to them (\(\vec{n}_3\) is not a multiple of \(\vec{n}_1\)), so all three planes intersect along a single straight line.

Q4: Determine the geometric configuration of: \(x + y + z = 1\), \(x + 2y + 3z = 4\), and \(2x + 3y + 4z = 7\).

Solution: Notice that \(\vec{n}_1 + \vec{n}_2 = (2, 3, 4) = \vec{n}_3\), so the normal vectors are coplanar. Adding the first two equations gives \(2x + 3y + 4z = 5\), which contradicts the third equation (\(2x + 3y + 4z = 7\)). Since no two planes are parallel, they form a triangular prism (no solution).

Q5: Find the line of intersection of the three planes: \(x + y + z = 4\), \(x - y + z = 2\), and \(2x + 2z = 6\).

Solution: Adding the first two equations yields \(2x + 2z = 6\), which is identical to the third equation. Thus \(x + z = 3\) and \(y = 1\). Letting \(z = t\), we get \(x = 3 - t\). The three planes form a sheaf intersecting along the line \(\vec{r} = (3, 1, 0) + t(-1, 0, 1),\ t \in \mathbb{R}\).

9.5 Practice Questions

Q1: Find the perpendicular distance from the point \(P(4, -2)\) to the line \(3x - 4y + 5 = 0\) in \(\mathbb{R}^2\).

Solution: Apply the 2D formula: \(d = \dfrac{|3(4) - 4(-2) + 5|}{\sqrt{3^2 + (-4)^2}} = \dfrac{|12 + 8 + 5|}{\sqrt{25}} = \dfrac{25}{5} = \mathbf{5}\) units.

Q2: Calculate the distance from \(P(1, 2, 3)\) to the line \(\vec{r} = (2, 0, 1) + t(1, 2, -2)\) in \(\mathbb{R}^3\).

Solution: Let \(Q(2, 0, 1)\), so \(\vec{QP} = (-1, 2, 2)\) and \(\vec{d} = (1, 2, -2)\). Compute \(\vec{QP} \times \vec{d} = (-8, 0, -4)\). Then \(\|\vec{QP} \times \vec{d}\| = \sqrt{64 + 0 + 16} = \sqrt{80} = 4\sqrt{5}\), and \(\|\vec{d}\| = \sqrt{1 + 4 + 4} = 3\). Thus \(d = \mathbf{\dfrac{4\sqrt{5}}{3}}\).

Q3: Why cannot we use the 2D formula \(d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}\) directly for a line in \(\mathbb{R}^3\)?

Solution: In \(\mathbb{R}^3\), a single linear equation \(Ax + By + Cz + D = 0\) represents a plane, not a line, because a line in 3D has infinitely many perpendicular directions rather than a single unique normal vector.

Q4: Find the distance between the two parallel lines in \(\mathbb{R}^2\): \(5x + 12y - 10 = 0\) and \(5x + 12y + 16 = 0\).

Solution: Pick point \(P(2, 0)\) on the first line (since \(5(2) + 12(0) - 10 = 0\)). Its distance to the second line is \(d = \dfrac{|5(2) + 12(0) + 16|}{\sqrt{5^2 + 12^2}} = \dfrac{26}{13} = \mathbf{2}\) units.

Q5: Find the shortest distance from the origin \(O(0, 0, 0)\) to the line \(x = 1 + t,\ y = 2 - t,\ z = 2t\).

Solution: Using \(Q(1, 2, 0)\), \(\vec{QO} = (-1, -2, 0)\) and \(\vec{d} = (1, -1, 2)\). Then \(\vec{QO} \times \vec{d} = (-4, 2, 3)\), with magnitude \(\sqrt{16 + 4 + 9} = \sqrt{29}\). Since \(\|\vec{d}\| = \sqrt{1 + 1 + 4} = \sqrt{6}\), \(d = \mathbf{\sqrt{\dfrac{29}{6}}}\) (or \(\frac{\sqrt{174}}{6}\)).

9.6 Practice Questions

Q1: Find the perpendicular distance from the point \(P(3, -2, 5)\) to the plane \(2x - 3y + 6z - 14 = 0\).

Solution: \(d = \dfrac{|2(3) - 3(-2) + 6(5) - 14|}{\sqrt{2^2 + (-3)^2 + 6^2}} = \dfrac{|6 + 6 + 30 - 14|}{\sqrt{4 + 9 + 36}} = \dfrac{28}{7} = \mathbf{4}\) units.

Q2: Calculate the distance between the two parallel planes \(\pi_1: x - 2y + 2z = 5\) and \(\pi_2: 2x - 4y + 4z = 22\).

Solution: Divide \(\pi_2\) by 2 so both equations share the same normal vector \((1, -2, 2)\): \(\pi_2: x - 2y + 2z - 11 = 0\) and \(\pi_1: x - 2y + 2z - 5 = 0\). Then \(d = \dfrac{|-11 - (-5)|}{\sqrt{1^2 + (-2)^2 + 2^2}} = \dfrac{6}{3} = \mathbf{2}\) units.

Q3: If the distance from a point \(P\) to a plane \(\pi\) is calculated to be \(0\), what does that tell you about point \(P\)?

Solution: Point \(P\) lies directly on the plane \(\pi\) (its coordinates satisfy the plane's Cartesian equation).

Q4: Find the distance between the skew lines \(L_1: \vec{r} = (1, 0, -1) + s(1, 1, 0)\) and \(L_2: \vec{r} = (0, 2, 1) + t(0, 1, 1)\).

Solution: \(\vec{n} = \vec{d}_1 \times \vec{d}_2 = (1, 1, 0) \times (0, 1, 1) = (1, -1, 1)\), so \(\|\vec{n}\| = \sqrt{3}\). With \(P_1(1, 0, -1)\) and \(P_2(0, 2, 1)\), \(\vec{P_1P_2} = (-1, 2, 2)\). Thus \(d = \dfrac{|(-1)(1) + 2(-1) + 2(1)|}{\sqrt{3}} = \dfrac{|-1|}{\sqrt{3}} = \mathbf{\dfrac{1}{\sqrt{3}}}\) (or \(\frac{\sqrt{3}}{3}\)).

Q5: Find the value(s) of \(k\) such that the distance from \(P(1, k, 2)\) to the plane \(2x + y - 2z + 5 = 0\) is \(3\).

Solution: Set up the distance equation: \(\dfrac{|2(1) + k - 2(2) + 5|}{\sqrt{2^2 + 1^2 + (-2)^2}} = 3 \implies \dfrac{|k + 3|}{3} = 3 \implies |k + 3| = 9\). Solving gives \(k + 3 = 9\) or \(k + 3 = -9\), so \(k = 6\) or \(k = -12\).
